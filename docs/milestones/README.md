# Meilenstein-Pläne

Pro Meilenstein eine Datei `M<n>.md` mit:
1. **Ziel** (1–2 Sätze, Spec-Teile)
2. **Aufgaben** als Checkliste in Abhängigkeitsreihenfolge
3. **Abnahmekriterien** (Tests, was im iPhone-Viewport sichtbar sein muss)
4. **Abschlussnotiz** (was gebaut wurde, was offen blieb → BACKLOG)
